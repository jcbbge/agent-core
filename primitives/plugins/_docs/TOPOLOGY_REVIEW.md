# Topology Peer Review: Synthesis & Re-orientation

## The Core Finding
The peer protocol correctly identified the critical failure mode of our outer-edge topology: **Invisible Autonomy is Hostile.** 

The ideas that *observe, shape probability, and warn* are brilliant. The ideas that *act autonomously on core artifacts (code, UI, tools, continuity) without human consent* will catastrophically collapse trust.

## The Winning Primitives (Constrained & Reframed)

### 1. Epigenetic Gravity (Exemplar Priming)
*Reframing:* We cannot inject into the KV cache directly. Instead, we use semantic mapping. When Alembic detects a workflow pattern, it autonomously pre-fetches the user's *best matching historical code* (AST-compressed via Composto) and places it silently at the top of the context window. It doesn't tell the model "be functional"; it just proves that functional is the only accepted dialect.

### 2. Stigmergic Pain Maps (Observability, not Action)
*Reframing:* The daemon does not refactor code. It paints the map. If the agent struggles with a file 5 times in a week, it places a `pain_marker` on that file in SurrealDB. The `alembic-boot` sequence warns the user at the start of the session: "Warning: `arc/schema.ts` has accumulated high agent friction. Consider refactoring for machine-symbiosis."

### 3. Mycelial Context Bleed (Provenance-Tagged)
*Reframing:* Patterns cross-pollinate, but never silently. If an architectural decision from Strudel is applied to Arc, the agent is forced to cite its source: "[Mycelial Bleed] Sourced from Strudel architecture decision 2026-06-20."

### 4. Adversarial Immune Daemons (Red-Teaming)
*Reframing:* Not real-time on every keystroke. When a `macro_intent` is collapsed (a large feature is finished), a secondary, highly critical model (e.g., Sonnet 3.5) runs a post-flight analysis specifically looking for security flaws, race conditions, and architectural rot before the final commit is allowed.

### 5. Temporal Pre-Computing (Read-Only Warming)
*Reframing:* Daemons never mutate state. They only assemble context. If the habit pattern predicts work on Arc, the daemon runs Composto, updates the Coraline index, and checks the db status so the environment is "hot" when the user types `pi`.

## The Rejected Extremes
- **Autophagic Tool Generation:** Security nightmare, creates a junkyard of unmaintained code. We build tools deliberately.
- **Fluid UI Morphogenesis:** Destroys developer muscle memory. UI must be predictable.
- **Semantic Code-Folding:** Fights the entire ecosystem (git, grep, IDEs) by removing text as ground truth.
- **Resonance-Driven CI/CD:** Gating tests behind subjective `phi` guarantees shipped regressions.
- **Hard Ghost Handshake:** Refusing to operate on a hash mismatch is brittle; it must be a diagnostic warning, not a hard crash.
