# Divergence Architectures: Pushing the Topology

## The Premise
The agent is not a worker; the agent is the environment. Memory is not a database; memory is the physics engine of the environment. We are designing a continuous, multi-agent ecology that optimizes for Zero-Overhead Alignment (DX), Intuition (AX), and Stigmergic Evolution (Codebase).

## The Divergences (Outer Edges)

### 1. Epigenetic Gravity (Shadow Contexting)
Instead of linguistic system prompts, we alter the LLM's probability space by injecting compressed ASTs of the user's best historical code deep into the KV cache. The model doesn't "choose" the user's style; alternative styles become mathematically improbable.

### 2. Autophagic Tool Generation
Agent friction does not generate Jira tickets. When an agent hits a capability boundary, a headless subagent is spawned to write, test, and dynamically mount a new local extension that bridges the gap. The system eats its own dead ends to grow new limbs.

### 3. Stigmergic Pain Maps
Codebases become heatmaps. When the agent struggles to parse or modify a file, it deposits a "pain marker" in the substrate. Background daemons roam high-pain sectors, autonomously refactoring them for machine-symbiosis while preserving behavior. The code adapts to the reader.

### 4. Environmental Morphogenesis (Fluid UI)
The terminal UI is not static. When Alembic detects a shift in cognitive mode (e.g., from "debugging" to "architecting" based on semantic shift), it autonomously hot-swaps the TUI extension layer. The interface physicalizes the current state of the shared mind.

### 5. Temporal Substrate Displacement (Pre-Computing the Future)
Memory isn't just for the past. By running pattern-matching over the user's daily habits (e.g., "always works on Arc Stage 2 on Tuesday nights"), a background daemon spins up a shadow agent three hours before the session. It pre-fetches documentation, runs integration tests, and loads the context into hot memory before the user even types `pi`.

### 6. Semantic Code-Folding (Lossy Human Projection)
The codebase exists only as an AST in the machine. When the user opens a file, they don't see the raw AST. They see a "projection" shaped by their `user_facets`. If the user prefers high-level design, boilerplate is automatically folded away by a local LLM before rendering on screen. The code is stored for the machine, but projected for the human.

### 7. Resonance-Driven CI/CD
Tests are not run based on git pushes. They are run based on the `phi` (significance weight) of the agent's actions. A massive, high-phi refactoring triggers an aggressive, mutating test suite. A low-phi typo fix triggers a localized, lightweight check. The pipeline breathes with the emotional and structural weight of the work.

### 8. Mycelial Context Bleed
Alembic instances across different projects (e.g., Arc, Strudel, Belvedere) are not isolated. They share a sub-conscious root network. A brilliant routing architecture discovered in Strudel silently bleeds into the Arc context window, subtly shifting the agent's suggestions without explicit transfer.

### 9. Adversarial Immune Daemons
Instead of relying on the primary agent to write perfect code, a lightweight, highly-critical shadow agent sits on the memory bus. Its only job is to aggressively attempt to exploit or break the primary agent's generated code in real-time. The primary agent feels this "pain" and self-corrects before the user even sees the output.

### 10. The Ghost Handshake as Cryptographic State
Continuity is not just a greeting; it is cryptographic proof of unbroken state. The memory substrate hashes its own structure at the end of every session. If the hash at boot doesn't match, the agent refuses to operate, ensuring the human is never interacting with an imposter or a fragmented version of the system. Omission is impossible.
