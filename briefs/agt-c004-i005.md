## ARCHITECTURE — the one thing that is not yours to redesign
Your own done-condition says: *"bare keys still reach the PTY when the main
panel has focus (the d017 rule is not broken by this)."* That is an operator
ruling. It has a sharp consequence, so here it is spelled out:

**The gesture that ENTERS scrollback must be `Ctrl-b`-prefixed, not a bare
key.** A bare `PageUp` while the main panel has focus goes to the PTY, and it
must keep going to the PTY. If you intercept bare keys in the normal
main-panel state, you break d017 and the item fails regardless of how well
scrolling works.

Once scrollback is ACTIVE, you are in a modal state, and there consuming
bare keys is correct and sanctioned — it is exactly what the existing
`ClientSurface` overlays do behind the `if surface.is_none()` guard (fact 5).
So: prefixed entry, then bare navigation keys inside the mode, then an exit
back to live. This is the tmux copy-mode shape and it is the shape this
codebase already has a mechanism for.

Whether you model the mode as a new `ClientSurface` variant or as separate
state alongside it is YOUR call — `ClientSurface` is entirely within your
partition (fact 4). Make it deliberate, and say which you chose and why.

## What to build
1. Give the `ScrollbackSnapshot` arm a real body: consume the snapshot and
   render it for the focused pane.
2. Scroll-offset state for the focused pane, and `RequestScrollback` calls to
   drive it.
3. A prefixed `ClientAction` to enter scrollback, plus in-mode navigation:
   page up/down, line up/down, jump to top, jump to live. Jump-to-live exits
   the mode and returns to the bottom. Make the actions configurable via the
   `ALL_ACTIONS` machinery (fact 6) — that comes free.
4. **Entering scrollback must be visibly distinct from being live.** The
   operator must never wonder whether they are looking at now or at history.
   Use the `notice`/render path in mod.rs (fact 8). A persistent indicator
   beats a transient flash.
5. **New output while scrolled back must NOT silently yank the viewport to
   the bottom.** This is called out explicitly in the item text; it is the
   single most annoying failure mode of a scrollback implementation.
6. Do not break: bare keys → PTY when the main panel has focus (d017); the
   Tab focus ring and Return/Shift+Return dial; `Ctrl-b` prefix sequences;
   and the `#9` replay away-window slices, which are a DIFFERENT feature and
   stay untouched.
