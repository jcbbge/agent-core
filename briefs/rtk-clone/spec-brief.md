HARD REQUIREMENT from the operator, verbatim intent: **there is no fallback — this tool must work, period.** That means: (a) it fully replaces rtk (no rtk on the machine afterward); (b) truth over compactness — if a filter cannot parse its input, it emits the RAW output unchanged; underlying command exit codes are ALWAYS propagated faithfully; any truncation is visibly marked (`[+N omitted]`); there is no failure mode that prints a banner instead of output, no exit-0-on-error, no silent empty result. The rtk bug catalog (false-identical diff, silent 0-results find, integrity banners with exit 0) is the anti-spec: every one must be structurally impossible.
